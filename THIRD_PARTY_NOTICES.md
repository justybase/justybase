## Components not distributed as NuGet packages

- IBM Netezza server software and its client libraries are not bundled; the application connects over the network.
- Oracle Instant Client is not bundled; Oracle connections require a separately installed, licensed client.
- The Microsoft Access Database Engine and the Java UCanAccess runtime are not bundled; Access support uses the managed `JustyBase.UCanAccessCs` provider.
- `llama-server` and GGUF model files are downloaded on demand for optional local AI features and are not part of the installer.
